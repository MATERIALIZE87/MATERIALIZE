Cómo usarlo

  1. Importar: exporta desde QGIS la capa de provincias como GeoJSON y pulsa «Importar provincias». Cada provincia se detecta como un polígono real.
  2. Pintar: elige un país en la lista de la derecha y pinta arrastrando sobre las provincias (B). Las conquistas se ven en tono claro y luego pasan al color normal.
  3. Seleccionar (V): clic en provincias (Mayús para añadir, arrastrar para seleccionar en rectángulo, doble clic para todo el país). Luego agrupa (Ctrl+G), desagrupa, cambia color o transparencia.
  4. Grupos: al pintar o seleccionar una provincia de un grupo se edita el grupo entero (mantén Alt para ignorarlo).
  5. Textos e imágenes: herramienta Texto (T) o Imagen; muévelos con Seleccionar, cambia tamaño desde la esquina o con la rueda + Ctrl.
  6. Fotogramas: «+ Fotograma» copia el estado actual. Pinta los cambios en el nuevo. Ajusta Duración, Transición, Aclarado y Propagación. 📷 guarda la cámara (zoom) de cada fotograma.
  7. Vídeo: «Exportar vídeo» graba un .mp4/.webm listo para YouTube.
  8. Atajos: Ctrl+Z / Ctrl+Y, Supr para borrar, Espacio + arrastrar para mover, rueda para zoom, N nuevo fotograma, ←/→ cambiar de fotograma.

Todo se guarda automáticamente en este navegador. Usa «Guardar proyecto» para tener una copia (.json).
